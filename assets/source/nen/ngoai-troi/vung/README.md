# Bản đồ – phân vùng & khóa
Đặt đè lên `ban-do-the-gioi.png` (1448x1086, cùng kích thước):
- `mask_<vung>.png`: mặt nạ trắng/đen từng vùng (hoa, kim, moc, thuy, tho) + `mask_trung-tam.png` (khu trung tâm, luôn mở). Dùng để biết con trỏ đang ở vùng nào.
- `khoa_<vung>.png`: lớp phủ khi vùng còn KHÓA (tối + mất màu + sương + ổ khóa). Mở vùng = bỏ lớp này.
- `chon_<vung>.png`: viền vàng phát sáng khi đang chọn vùng.
Ban đầu: chỉ trung tâm (Nhà, Trường, Chợ, Võ đường) mở; 5 vùng khóa.
Tâm vùng (đặt ổ khóa / icon): Hỏa (400,190), Kim (1170,250), Mộc (230,470), Thủy (380,880), Thổ (1220,640).
