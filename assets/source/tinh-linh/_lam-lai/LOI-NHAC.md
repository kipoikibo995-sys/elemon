# Làm lại 7 bảng vẽ nhầm thành hổ

Mỗi lần tạo: mở cuộc trò chuyện mới, đính kèm ảnh `<con>_tham-chieu.png` trong thư mục này, dán lời nhắc của bảng đó.
Tạo xong, lưu đè đúng tên file vào `assets/source/tinh-linh/`, rồi báo để cắt khung.

Mẹo: tạo theo thứ tự Con → Nhi → Thiếu niên. Khi tạo bảng sau, đính kèm thêm bảng vừa tạo được để giữ đúng một con.

## Phần chung (dán ở đầu mỗi lời nhắc)

```
Pixel art sprite sheet for a handheld game, same art style as the attached reference.
Canvas 1254x1254, flat solid magenta background #FF00FF everywhere (no gradient, no floor, no shadow, no text, no grid lines).
Grid of 4 columns x 4 rows, one character per cell, centered, all at the same size, feet on the same line in every cell, facing right, sprites must not touch each other.
Row 1: idle breathing, 4 frames.
Row 2: walking, 4 frames.
Row 3: eating, happy jump, sad/hungry, sick (dizzy swirls).
Row 4: sleeping 2 frames (with zzz), waking up / yawning, stretching.
IMPORTANT: the character is NOT a tiger and NOT a cat. The 4x4 picture on the right of the reference only shows the grid layout, do not copy that animal.
```

```
Character: Hoa Quy BABY stage, a tiny chubby lava TURTLE hatchling that just came out of the attached dark lava egg. Cute, very round, no stripes, no fur, no mane.
```

```

Scaly reptile skin, no stripes, no fur, no mane.
