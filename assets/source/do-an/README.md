# Đồ ăn (HoLua) – 48 món, PNG nền trong suốt
File `<Hệ>_<tier>_<tên>.png`, `catalog.json` {file, he, tier, name}. Dùng làm icon menu và đặt vào bát (≈55–70px trên phòng 1448x1086).

## Nhóm
- Hoa / Kim / Moc / Thuy / Tho: 8 món mỗi hệ. Tier 1–2 rẻ (no bụng), 3–6 thường (no + vui + chút chỉ số), 7–8 hiếm (cộng chỉ số chính của hệ nhiều, có món dùng cho tiến hóa).
- DacBiet: 1 thuốc chữa ốm · 2 viên thảo dược (phòng ốm) · 3 kẹo vitamin (vui) · 4 nước tăng lực (hồi năng lượng) · 5 xà phòng tắm (sạch) · 6 bóng đồ chơi (vui) · 7 đá tiến hóa · 8 ngọc hồn (boss rơi, điều kiện Huyền thoại / phòng Lv4).

## Luật điểm hệ (khớp luật phòng)
- Ăn đồ CÙNG hệ pet → giữ / hồi điểm hệ gốc.
- Ăn đồ KHÁC hệ → điểm hệ của món tăng, điểm hệ gốc giảm (ảnh hưởng nhánh tiến hóa, sức mạnh hệ gốc).
- Món tier cao kéo điểm hệ mạnh hơn.
(Số liệu cân bằng chỉnh sau.)
